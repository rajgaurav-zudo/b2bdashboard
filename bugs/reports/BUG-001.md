# BUG-001 — CSV delimiter detection counts punctuation inside quoted headers

- Status: Cleared
- Severity: Medium
- First observed: 2026-09-17
- Last tested: 2026-09-21
- Latest tested revision and local changes: `7855f7c` plus the uncommitted BUG-002 fix in `api/app/ingest/reader.py` and `api/tests/test_reader.py`.
- Area / source locations: [`_sniff_separator`, reader.py line 45](../../api/app/ingest/reader.py); called by `read_table` at line 121.
- Run logs: [2026-09-17 initial pass](../runs/2026-09-17-initial.md); [2026-09-17 Tangent pass 01](../runs/2026-09-17-tangent-01.md); [2026-09-17 Tangent pass 02](../runs/2026-09-17-tangent-02.md); [2026-09-21 fix verification](../runs/2026-09-21-fix-verification.md)

## Reproduction

Requires Python 3 only. Uses synthetic data and executes the actual helper body extracted with Python's AST, without importing application modules or accessing services.

1. From the repository root run `python3 bugs/runs/2026-09-17-reader-check.py`.
2. The quoted-header test supplies this valid semicolon-delimited input:

   ```csv
   "Last, First, Middle";city
   "Doe, Jane, M";Lisbon
   ```

3. Observe `test_bug_001_quoted_header_delimiters` fail.

## Expected result

The detector returns `;`, the delimiter separating the two columns. Commas enclosed inside a quoted field belong to that field.

## Actual result and evidence

The detector returns `,` because it counts every comma in the header, including quoted punctuation:

```text
AssertionError: ',' != ';'
```

The other three helper test methods pass, including plain comma/tab/semicolon/pipe detection, six record-count cases, and newline normalization.

## Impact

Valid semicolon exports with sufficiently comma-heavy quoted headers receive the wrong separator. `read_table` passes that incorrect separator directly to its CSV parser. The helper defect is confirmed; the final upload/dashboard behavior was not exercised because Python application dependencies are absent and database/auth workflows are excluded from this pass.
