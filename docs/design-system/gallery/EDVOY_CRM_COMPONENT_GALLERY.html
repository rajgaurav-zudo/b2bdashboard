Cards and panels are flat (1px border, no shadow). Shadows belong to floating layers (popover, tooltip, toast, drawer), raised/filled segments, and one scoped in-flow exception: the investigation context bar (N2). There are no general card shadows.

Shell & navigation

Navigation changes location (aria-current). Selection changes focus in place (aria-checked / aria-pressed / aria-selected) and never auto-scrolls. Both segmented appearances accept either kind of state; the product context picks the appearance (P3). Shared nav rows scroll horizontally rather than clipping items.

Sign and arrow direction are arithmetic: ↑ means the value went up and ↓ means it went down. Colour, and whether an arrow appears, show desirability, which the consuming application classifies for each metric (higher-is-better, lower-is-better or neutral). Neutral and unchanged keep the sign and get no arrow. Hidden text names the meaning, so colour is never the only signal. Zero is the value 0. No target set and Comparison unavailable share the compact dash but each carry their own accessible text and legend.

Workflow

Drawer anatomy and modal mechanics come from the rc2.36 Filters drawer, which the brief accepts. Open filters launches the real modal: focus moves to the title, Tab and Shift+Tab stay inside, the page behind is inert, Escape / × / Cancel / scrim close it, and focus returns to the trigger. The draft, Reset and Apply behaviour is this demo's policy, not a universal rule; each product sets its own.
